# API Reference

The `bakery-user` application is a consumer frontend and does not serve its own APIs. 

It heavily relies on the following backend microservices to function:
* **[Auth Service](https://github.com/amankrmj09/bakery_auth_service/blob/main/API_REFERENCE.md)** (for user registration, profile management, and login)
* **[Product Service](https://github.com/amankrmj09/bakery_product_service/blob/main/API_REFERENCE.md)** (for browsing the shop and storefront)
* **[Cart Service](https://github.com/amankrmj09/bakery_cart_service/blob/main/API_REFERENCE.md)** (for managing active shopping carts)
* **[Order Service](https://github.com/amankrmj09/bakery_order_service/blob/main/API_REFERENCE.md)** (for placing orders and viewing order history)
* **[Payment Service](https://github.com/amankrmj09/bakery_payment_service/blob/main/API_REFERENCE.md)** (for processing checkout transactions)

Please refer to their respective repositories for detailed endpoint specifications.
